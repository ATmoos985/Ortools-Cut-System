# 联合 A+B 小邻域优化（LNS）子模型规格 — 定版 v2（评审通过，待实现）

> v2 变更：纳入评审 6 点收紧 + 锁定参数。第一版求解器 = SCIP/MPSolver（不升 OR-Tools）。
> 第一版实现目标：**在一个闭包邻域内，固定总车数和总废边，证明联合列模型至少能找到一处局部降组。**

## 0. 目标与定位

把序号组从 55 往 47 拉。已证实：序号组的唯一杠杆是「装配/联合决策」，不是 A 层花型集
（人工花型集喂分阶段装配仍得 55；人工联合决策得 47，得率/过量产完全相同）。本子模型在
**已得的 55 解**附近做 LNS：每轮解冻一个**闭包邻域**（一批完整车/配置涉及的所有订单 + 花型），
**联合**重决「每个花型用多少车 + 每车装哪些订单」，仅接受**全局序号组严格下降**且车数/废边不变的改动。

LNS 为何能成、全局 set-partition 为何失败：全局死于「列池爆炸 + 弱 LP 无定价」。LNS 把配置列
枚举限制在小邻域，列数可控可穷举，绕开列生成定价难题。

---

## 1. 邻域输入（每轮）—— 闭包式，非按编号零散解冻

**邻域选择算法（评审点 6，第一版固定用「订单碎裂闭包」，不用「共享宽度可达」以防扩散过远）**：
1. 对 55 解每个订单，算其**跨配置数**（落在几个不同「整卷配置」里）。
2. 按跨配置数降序，取 top 若干订单作种子。
3. 找出这些种子订单当前所在的**全部配置/车**。
4. **闭包**：把这些配置/车里涉及的**所有订单**纳入 `O_free`（评审点 3·方案 A：解冻的是
   完整车/完整配置，不是只解冻几个编号——保证邻域闭包完整，外部订单不会被破坏）。
5. `P_free` = 这些被解冻配置所属的花型集合（**第一版就到此为止，不再按共享宽度向外扩**）。
6. 若闭包规模超限，**减少 top 种子订单数量**重算，直到满足上限。

- **冻结区（不动）**：邻域外所有花型车数、订单→槽位分配、产出，全部固定。
- **闭包保证**：`O_free` 外的任何订单都不出现在任何解冻配置里 → 冻结区订单卷数天然不被触碰。

---

## 2. 决策变量（列式 / 配置列）

采用列式形式（直接表达组数代理、SCIP/CP-SAT 均友好），不用 `a[o,p,k,s]` 全展开（变量爆炸+对称性）。

- **配置列 `c ∈ C`**（预枚举）= (花型 `p(c)`, 该花型每槽位放哪个订单)。决定其产出 (宽度,订单) 卷集合、
  废边 `w(c)`、所属花型 `p(c)`。**仅由 `O_free` 内订单构成**（闭包外订单不入列，评审点 3）。
- `n[c] ∈ ℤ≥0`：配置 `c` 生产多少车。
- `y[c] ∈ {0,1}`：配置 `c` 是否启用（reified：`y[c]=0 ⟺ n[c]=0`）。
- `x[p] = Σ_{c:p(c)=p} n[c]`：派生量（花型 p 车数）。

**配置列池 `C` 的构成（评审点 4，硬性）**：
- **必含**：原 55 解里该邻域**当前使用的全部配置**。→ 保证子模型至少能复现原解；模型若不可行，
  即可断定是「邻域真无解」而非「列池漏了当前解」。
- **再加**：`P_free` 各花型在 `O_free` 订单上的其他合法槽位指派（枚举，受 `|C| ≤ 2000` 截断；
  截断时**优先保留**必含列 + 覆盖更多订单/更均衡的列，并 log 丢弃数）。

> **`Σ y[c]` 是「邻域活跃配置数」代理目标，不等于最终全局序号组（评审点 1）**。回填全局后，
> 邻域边界配置可能与冻结区相邻配置合并，也受 resequenceBySort 影响。故**真实组数一律以
> `SequenceGroupPostProcessor.computeGroupStats` 回填重算为准**（见 §5），模型内 `Σ y[c]` 只用于驱动搜索。
> 第一版不引入 `run[c]`/块变量。

---

## 3. 硬约束（第一版全部取等号，评审点 2）

1. **需求精确满足**：对每个 `o ∈ O_free`，`Σ_c slots_o(c)·n[c] = demand[o]`（等式，无欠产、无过量产）。
2. **槽位合法**：配置 `c` 槽位多重集 = 其花型宽度多重集（枚举期保证，非运行期约束）。
3. **车数固定**：`Σ_{c} n[c] = B_cars`，`B_cars` = 邻域原解车数。（第一版 `=`，不用 `≤`。）
4. **废边固定**：`Σ_c w(c)·n[c] = B_waste`，`B_waste` = 邻域原解废边。（第一版 `=`，不用 `≤`。）
5. **不许凭空造数据**：配置只用原始委托存在的宽度/订单；闭包外订单不入任何列（§1/§2 已保证）。
6. **链接**：reified `y[c]=0 ⟹ n[c]=0`（CP-SAT）/ big-M（SCIP 回退）。

> 固定车数+废边的理由（评审点 2）：本版只验证「联合分配能否减组」，不重做得率优化。固定二者→
> 变量少、解释干净、风险最低。局部能降组后，再放宽成 `≤` 探索得率-组数权衡。

---

## 4. 目标函数（第一版两层，评审点 5）

- **Stage 1**：`min Σ_c y[c]`（邻域活跃配置数代理）。
- **Stage 2**：在 Stage 1 最优值下，`min (小车数组 + 奇数车数组 + 订单跨配置数)`。

> 花型种类、废边**不进目标**（评审点 5）：废边已是等式硬约束；花型种类可能与降组冲突。

---

## 5. 接受准则（回填全局后重算，防伪解）

子模型解出 → 回填进全局 55 解 → 重算全局指标，**全部满足才接受**：

- 全局**车数不增**（= 原解）。
- 全局**废边不增**（= 原解）。
- **逐编号订单卷数完全一致**（含冻结区）——防伪解硬闸，参照 InstructionConverter 现有 exact-demand 校验。
- 全局**序号组严格下降**（`SequenceGroupPostProcessor.computeGroupStats` 实测，不信子模型 proxy）。
- 否则**回滚该轮**，换邻域。

**每轮日志**：邻域选择原因 + `O_free`/`P_free` + 列池大小(必含/枚举/丢弃) + 前后全局序号组 +
前后废边 + 被移动订单编号 + 子模型 status/耗时。

**LNS 外层**：多轮迭代，邻域轮转（碎裂度降序 + 编号升序，确定性）；连续 K 轮无改进则停。
求解器单线程固定种子。

## 6. 定版参数（锁定）

| 项 | 值 |
|---|---|
| 求解器 | **SCIP / MPSolver，暂不升 9.11**（CP-SAT 在 9.10 崩溃，已实测；升级风险推迟到被证据 justified） |
| 邻域：订单闭包 `|O_free|` | **≤ 8** |
| 邻域：花型 `|P_free|` | **≤ 10** |
| 配置列 `|C|` | **≤ 2000**（必含原解列优先保留） |
| 车数 | **= B_cars**（等式） |
| 废边 | **= B_waste**（等式） |
| 接受准则 | **仅接受全局序号组严格下降** |
| 开关 | 默认关闭，仅 `B5SixianTest` 或显式参数启用；生产路径在验证通过前不变 |
| 基线 | `sixian.csv` + `B5SixianTest` 已单独提交（d3e208c），再做 LNS |

## 7. 落地位置（实现时）

- 入口：`InstructionConverter` 选出 55 解后、回填指令前，加可选 LNS 后处理阶段（默认关）。
- 复用：`SequenceGroupPostProcessor.computeGroupStats`（真组数校验）、
  `AssignmentMIPSolver.buildBlocksFromWidthSlotAssignments`（配置/块构造）、PatternGenerator 池。
- 求解器：现有 `MPSolver.createSolver("SCIP")` 路径（单线程、固定种子，沿用 LegacyOrder 的确定性参数）。

---

## 8. 第一版验收目标（评审锁定）

> **在一个闭包邻域内，固定总车数和总废边，证明联合列模型至少能找到一处局部降组。**

跑通这一点 → 证明联合方向对，再考虑扩大邻域 / 升级 CP-SAT；跑不通 → 连联合也到不了 47，止损。
