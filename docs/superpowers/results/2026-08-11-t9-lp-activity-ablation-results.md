# T9 LP 活跃度系数消融结果

## 核心结论

本轮离线消融否定了“只把 `lpActivity` 从百万级主导项降为零或弱信号，就能找回目标花型”的路线。

- 基线 `λ=1,000,000`：固定目标在 Top60/Top120 中均命中 1 种花型、1 列。
- 完全消融 `λ=0`：Top60/Top120 目标命中均降为 0；Top60 相对基线替换 55 个成员，新增成员全部不在固定目标中。
- 弱信号 `λ=10`：Top60/Top120 目标命中同样均为 0；Top60 相对基线替换 54 个成员，新增成员也全部不在固定目标中。
- `λ=0` 与 `λ=10` 的 Top120 成员集合完全相同，说明弱信号没有改变本实验的候选覆盖结论。

因此，不把 `lpActivity` 系数调整接入生产，也不为这条失败路线消耗一次 180 秒 T9 完整求解。百万权重确实放大了 LP 偏好，但不是目标花型缺失的充分根因；去掉它以后，现有结构分仍然无法识别这些花型的组合价值。

13 个因 `MISSING_RESIDUAL_WIDTH` 被门禁排除的目标列不属于本次消融，门禁逻辑保持不变，后续单独研究。

消融明细见 [2026-08-11-t9-lp-activity-ablation.csv](./2026-08-11-t9-lp-activity-ablation.csv)。

## 实验口径

- 输入快照：`2026-08-11-t9-key-pattern-selection-audit.csv`
- 输入 SHA-256：`fb72710f5fa365331577cddcdfe15b4ea0481f88f9de5c5c586200b4d69e2f41`
- 输入总量：55,941 种花型，其中 eligible 4,688 种。
- 固定诊断目标：31 列、27 种花型；其中 eligible 16 种、18 列，ineligible 11 种、13 列。
- eligible、结构分量、签名 tie-break、Top60/Top120 截断均不变。
- 本轮只改变 `lpActivity` 系数 `λ`。

离线重算公式：

```text
structuralScore = residualScarcity × 1,000
                + coveredResidualOrders × 10
                + wasteFit

score(λ) = lpActivity × λ + structuralScore
```

排序规则保持为 `score` 降序、`patternSignature` 升序。

三个场景：

| 场景 | λ | 作用 |
|---|---:|---|
| baseline | 1,000,000 | 复现当前生产排名 |
| lambda0 | 0 | 完全移除 LP 活跃度 |
| lambda10 | 10 | 把 LP 活跃度降为弱信号 |

eligible 花型的最大 `lpActivity` 为 4.405415912，因此 `λ=10` 的最大附加分为 44.05415912，已经与结构分量处于可比较量级，而不再形成百万级分层门槛。

## 基线验真

重算不是近似复现：

- 4,688/4,688 个 eligible 花型的名次与输入快照完全一致。
- 60/60 个 Top60 成员与输入快照完全一致。
- eligible 签名 4,688 个且全部唯一。

输入 CSV 只保留 9 位小数，因此重算分数与生成快照时的内部高精度分数可能存在末位差异；排名和截断集合没有差异。

|---|---:|---:|---:|---:|---:|---:|---:|
| baseline | 1 / 1 | 1 / 1 | 0 | 0 | 0 | 60 | 55 / 5 |
| λ=0 | 0 / 0 | 0 / 0 | 55 | 0 | 55 | 5 | 0 / 60 |

这里的“非固定目标”只表示不属于本次固定 31 列诊断 oracle，不等于已经证明这些花型对其他整数解无用。人工 31 列不是唯一最优结构；但本实验的验收条件是目标覆盖改善，而两个消融场景都没有获得任何目标增量，反而丢掉了唯一已有命中，因此不能进入生产 A/B。

Top120 的集合关系进一步说明弱信号没有带来有效覆盖变化：

| 对照 | Top120 交集 |
|---|---:|
| baseline vs λ=0 | 66 / 120 |
| baseline vs λ=10 | 66 / 120 |
| λ=0 vs λ=10 | 120 / 120 |

## 决策与下一条研究路线

本轮决策如下：

1. 保持生产 `lpActivity` 系数不变，不接入 `λ=0` 或 `λ=10`。
2. 停止继续扫描 LP 系数；当前证据不支持通过权重微调突破 T9。
3. 不运行 T9 180 秒完整求解，因为离线候选门槛已经失败，运行只会增加成本而不能验证本轮假设。
4. 下一步转向组合级互补特征审计：先定义二列/三列束在订单闭合、车数、废边、odd、one-car 上的联合残差改善，再检查固定目标束能否被现有候选物化和排入有限预算。
5. 13 个 `MISSING_RESIDUAL_WIDTH` 胶水花型继续作为独立问题；在组合级信号得到验证前，不与评分改动混合。

根因结论由原先“LP 百万权重压制目标”修正为：**LP 百万权重是放大器，但单花型结构分同样与组合级整数价值不匹配。仅调 `lpActivity` 系数不是突破路径。**
