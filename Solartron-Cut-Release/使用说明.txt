太阳诱电-排程切割优化系统 - 独立交付包
========================================

本目录包含了独立运行“排程切割优化系统”的所有必须文件。

【如何运行】
1. 双击运行 `一键启动.bat`。
2. 弹出的黑色窗口是系统的后台服务，请勿关闭（关闭会导致系统退出）。
3. 服务会在几秒内启动完毕，并自动打开默认浏览器访问系统。
   （如果没有自动打开，您可以手动在浏览器中输入：http://localhost:8081）

【文件及目录说明】
- 一键启动.bat       ：双击此文件可一键启动排程系统及其界面。
- app.jar            ：系统核心程序包。
- application.properties ：配置文件。如果遇到端口冲突，或需要修改默认参数，可以用记事本打开修改。
- 【输出】模板.xlsx  ：给用户导出用的标准Excel排程模板。
- exports/           ：该文件夹用于存放系统生成的输出文件。

【环境准备】
- 请确保运行本程序的电脑上已安装 Java 17 或以上版本。如果启动时黑色窗口闪退，请检查 Java 是否已正确安装。
